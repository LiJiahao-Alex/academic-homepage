# Jiahao Li · Academic Homepage

A bilingual static academic homepage for Jiahao Li. [English](https://lijiahao-alex.github.io/academic-homepage/) · [中文](https://lijiahao-alex.github.io/academic-homepage/zh.html)

- `index.html` and `zh.html` hold the English and Chinese pages. When editing shared content, update both pages.
- `style.css` is shared by both pages. `portrait.jpg` is the portrait from the original homepage.
- GitHub Pages publishes the repository root of `main`. Open either HTML file locally for a quick preview.
